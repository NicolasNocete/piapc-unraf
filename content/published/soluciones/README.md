# Soluciones liberables

Esta carpeta contiene orientaciones que pueden publicarse después de una actividad.

Cada archivo debe indicar:

- fecha o condición de publicación;
- si ofrece una respuesta única o criterios de análisis;
- errores frecuentes;
- qué elementos continúan requiriendo producción propia del estudiante.

No se almacenarán aquí consignas, soluciones, bancos de preguntas ni criterios privados de exámenes parciales.
