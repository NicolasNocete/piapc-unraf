# Sistema de contenidos PIAPC 2026

Esta carpeta contiene la fuente académica de los materiales de la asignatura **Programación de Inteligencia Artificial y Patrones de Comportamiento**.

Los contenidos se diseñan primero como documentos Markdown independientes de la futura aplicación web. Cada documento debe poder leerse, citarse y utilizarse sin depender de una interfaz particular.

## Principios

1. La teoría es introductoria, pero debe permitir comprender y cuestionar el funcionamiento de los sistemas utilizados.
2. La práctica se realiza sobre proyectos de videojuegos preparados específicamente para la cátedra.
3. OpenCode es el laboratorio de referencia, no el contenido de la materia.
4. Las capacidades se describen de forma transferible entre agentes, modelos, motores y lenguajes.
5. Una respuesta de un modelo no constituye evidencia de que una tarea esté correctamente resuelta.
6. Toda acción relevante debe ser verificable, segura y reversible.
7. Los materiales históricos ubicados en `repositorio/` quedan fuera de este sistema y no deben enlazarse desde actividades, ejemplos o evaluaciones.

## Laboratorio de referencia

El recorrido práctico utiliza el laboratorio Guardia de Sigilo. Su núcleo conceptual es independiente del motor y admite proyectos alternativos con evidencia equivalente.
