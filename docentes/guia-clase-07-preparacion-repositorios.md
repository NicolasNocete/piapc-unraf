# Guía docente: clase 7 - Preparación de repositorios para agentes

**Fecha:** 23 de septiembre de 2026<br>
**Modalidad:** virtual asincrónica

## Propósito

Preparar un repositorio para trabajo agéntico mediante instrucciones persistentes, permisos, validación y una línea de base verificable.

## Preparación previa

1. Revisar la plantilla de auditoría, las lecturas de contexto, Git, validación y seguridad.
2. Confirmar que los ejemplos no requieren secretos, instalación ni publicación.

## Materiales

- Repositorios y selección de contexto.
- Implementación incremental, Git y reversibilidad.
- Infraestructura de desarrollo y validación.
- Plantilla de auditoría de repositorio.

## Secuencia

1. Identificar estructura, instrucciones y comandos documentados.
2. Establecer permisos mínimos y una línea de base antes de editar.
3. Registrar riesgos, evidencia y condiciones de detención.

## Preguntas y respuestas esperables

- ¿Un archivo de instrucciones autoriza cualquier comando? No: documenta contexto; los permisos y la autorización siguen siendo explícitos y mínimos.
- ¿Por qué registrar una línea de base? Permite distinguir fallas preexistentes de efectos de una intervención posterior.

## Entregable o resultado esperado

Auditoría de repositorio con contexto, permisos, comandos autorizados y riesgos.

## Criterios de observación docente

- No propone escritura antes de entender el proyecto.
- Identifica un comando verificable y su resultado inicial.
- Reconoce prompt injection, secretos y cambios irreversibles como riesgos.
